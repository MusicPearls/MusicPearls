# Music Pearls

Music Pearls is a platform for classical music research and discovery. It provides detailed information about composers, their most significant works, and the various musical forms that have defined the evolution of Western classical music. The project is built as a full-stack application with a React frontend and a Node.js/Express backend, designed for both usability and scalability.

## Features

- Ranking of the most well-known classical compositions
- Overview of major musical forms and their usage
- Composer profiles with biographical and historical context
- Backend API integrated with Google Cloud Storage
- Responsive frontend optimized for different screen sizes

## Technology Stack

### Frontend
- React.JS
- Deployed via Vercel

### Backend
- Node.js with Express
- Dockerized for deployment
- Deployed on Google Cloud Run
- Secure access to Google Cloud Storage using a service account
